# המסלול שלי – מדריך קצר

**כתובת:** https://system-of-goals.github.io/hamaslul/
**הנתונים:** נשמרים רק בטלפון. מומלץ לשמור גיבוי פעם בשבוע (הגדרות ← שמור גיבוי לטלפון).

## התחלה (פעם אחת)
1. לפתוח את הכתובת ב-Chrome ← ⋮ ← "הוסף למסך הבית".
2. לבחור קוד של 4 ספרות (+ טביעת אצבע).
3. לטעון את קובץ הנתונים `my-data.json` (שמור אצלי בטלפון/במחשב – **לא** ב-GitHub, כי המאגר ציבורי) – "טען את הנתונים שלי" ולבחור את הקובץ, או לפתוח אותו, להעתיק את כל התוכן וללחוץ "הדבק נתונים שהעתקתי".
4. הגדרות ← התראות ← "הפעל התראות".

## יום רגיל
- **בוקר:** פותחים את "היום" ← בוחרים 💪 עם כוח / 🌱 מינימום.
- **קימה:** מסמנים ✔️ לפני 11:00 – שעת הקימה נרשמת לבד ביומן השינה.
- **לימוד 09:00–15:00:** "התחלתי / עצרתי" או "+30 דק׳". השיעורים של היום מופיעים בתוך המשימה – מסמנים אותם שם.
- **אחרי העבודה:** כושר ("סיימתי אימון" בדף הרגלים), בישול (בוחרים מתכון), ניקיון.
- **שינה:** מסמנים ✔️ אחרי 20:00 – שעת השינה נרשמת לבד.
- משימה שלא בוצעה – למחרת האתר שואל: להיום / לשישי / לוותר.

## שבוע
- **משמרת ארוכה / צהריים:** דף שבוע ← בוחרים את היום ← הכפתור המתאים.
- **יום חופש:** דף שבוע ← 🌴, או בסיכום השבועי.
- **שבוע מילואים / בית:** בראש דף שבוע, בסיכום השבועי, או בהגדרות (12 שבועות קדימה).
- **חמישי 15:00:** סיכום שבועי – הצלחות, מה נדחה, רמת לחץ, תודה, תכנון השבוע הבא.

## כשקשה
כפתור **🧭 בוא נחזור למסלול** – 7 צעדים קצרים. האתר גם מציע אותו לבד כשיש פיגור של 2 שיעורים, יומיים מתחת למינימום, או לחץ 4–5.

## שינויים
- **לו"ז קבוע:** הגדרות ← הלו"ז הקבוע (שם, ימים, שעות, מינימום, יעד לימוד).
- **יעדי שינה:** הגדרות ← יעדי שינה לפי חודש.
- **מטרות ושלבים:** דף מטרות ← לחיצה על תחום.
- **מתכונים:** הרגלים ← בישול ← ➕ או עריכה.
- **משפטים משלי:** הגדרות ← משפט היום.
